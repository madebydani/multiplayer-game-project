# Dirección artística

> **Estilo definitivo: pendiente de decisión del equipo.** Los recursos finales se generarán con ChatGPT y herramientas de imagen, bajo revisión humana. Claude Code solo integra.

## Criterios fijados por la especificación (§7)
- Bosque misterioso pero agradable.
- Estética 2D ilustrada plana, cámara cenital (top-down).
- Sombras suaves.
- Personajes reconocibles; supervivientes y monstruos distinguibles por **forma e icono**, no solo por color.
- Contraste suficiente para legibilidad y accesibilidad.

## Placeholders (fases 2–5)
Figuras geométricas simples (círculos, rectángulos) con colores y formas diferenciadas. No son arte final.
